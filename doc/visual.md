# 《Rooftop Apartment》视觉圣经

## 1. 视觉命题

- 方向：A2「屋顶生活记录簿」。
- 一句话：一册夹着账单、维修记录和未说出口的话的合租留言簿。
- 核心情绪：没有宏大灾难，只有会被记住的小决定。
- 标志瞬间：住户承认一件隐瞒后，关系批注紧随台词出现，随后在原位显影为暖窗与屋顶管道的现场图。
- 避免：社交 App 聊天气泡、房产仪表盘、温馨圆角卡片堆、图片回写顶部。

## 2. 构图与视角

- 响应式竖屏 DOM；390×844 与 320×568 主验收，桌面 Shell 最大 720 px，正文最大 610 px。
- 顶部 84–104 px：标题、公寓房间/时间、租金/秩序/声誉、44 px `Aa` 文字设置和 World 按钮。
- 中部：独立滚动时间线，按发生顺序混排玩家行动、叙述、住户台词、检定、状态和图片。
- 底部快速回复按文字量形成 148–310 px 的长短节奏，并以露出下一项暗示可横向滑动。
- 底部 104–152 px：横向快速回复与自由输入；World 抽屉提供住户、房间、公共柜和留言簿。
- 玩家消息靠右并配 32 px 头像；住户消息靠左，叙述保持书页正文形态。

## 3. 色彩

- 夜瓦 `#171718`、信纸 `#E5DDCF`、植物绿 `#63826B`、砖红 `#A85F4D`、窗灯 `#D4A860`、墨色 `#2B2925`。
- 正文对比至少 4.5:1；压力、秩序、声誉的变化同时显示文字与结构。
- 不使用粉色社交 App 渐变、玻璃、霓虹或大面积阴影。

## 4. 字体

- 叙述：`Songti SC, Noto Serif SC, Georgia, serif`，小/标准/大为 16/17/19 px，行高 1.75。
- 台词与行动：`Inter, PingFang SC, Noto Sans SC, sans-serif`，小/标准/大为 14/15/17 px，行高 1.5。
- 房间、数值和留言簿索引：等宽风格 9–12 px。
- 英文标题使用克制衬线体与 Title Case；中英文都允许自然换行，不强制单行大写。
- `Aa` 打开三档紧凑菜单；当前档同时用描边、底色和 `aria-pressed` 表达。选择写入 `localStorage.alteru_story_text_size`，不进入故事存档。

## 5. 形状、材质与光线

- 直边信纸、1 px 分隔线、软木板索引和胶带式批注；圆角不超过 4 px。
- 场景图平视或轻俯视，以暮色蓝、窗灯黄和植物绿构成生活化光线；阴影只表达纸层与抽屉。
- 入口使用完整彩色公寓母图；生成占位使用同一图的低饱和记录版本。

## 6. 角色、环境与资产

- 当前 AlterU 用户是第四位住户/故事主角；头像用于行动、住户页和关键剧情图片参考。
- 生图保留主角可辨识特征，但服装、姿态、室内光线与镜头服从生活场景；禁止滤镜自拍或让其他住户都变成用户脸。
- 固定环境元素：暮色公共厨房、四只不配套杯子、合拢账本、旧管道、屋顶植物和城市暖窗。图像无 UI、Logo、可读伪文字。
- 正式海报必须由 Aigram transit 生成，1024×1024，只出现英文 `ROOFTOP APARTMENT`；上方 25% 放标题，底部 20% 避开主体。

## 7. UI 与图标

- 使用同一套 1.75 px 线性 SVG：World、住户、房间、公共柜、留言簿、关闭、编辑、继续、图片和重试。
- 租金压力、公共秩序、邻里声誉均显示精确值和 3 px 状态轨，不能变成三张仪表卡。
- 检定展示技能、DC、骰点、修正、总值与 PASS/MISS；关系与公共状态批注紧邻原因。
- 住户页顶部为 48 px 主角头像、单行用户名和 You；下方为 Jo、Lin Cheng、Mo He。

## 8. 动效与特效

- 输入反馈 90 ms，消息入列 160 ms，抽屉 220 ms，检定落点 420 ms，图片显影 720 ms，状态轨更新 240 ms。
- 阅读位置以文字事件为锚点：开场先露出背景，行动后先露出结果；图片等待态与显影只在原位变化，不触发滚动。
- 图片从低对比记录底图显影为暖色生活现场；减少动态时取消位移与扫描，仅保留淡入。

## 9. 参考转译

- 合租留言簿：信息带有人留下的痕迹，但不复制便签软件 UI。
- 家庭账本：状态与来源可追溯，但不变成财务工具。
- 纪录片生活切片：角色自然存在于空间中，避免摆拍人像。

## 10. 反模式

- 禁止五轮结局、好感度爱心、约会 App 气泡、每句话掷骰或每回合生图。
- 禁止把关系变化只做成颜色；禁止匿名“关系改善”而没有人物和来源。
- 禁止固定陌生人替代用户主角；禁止把默认 `U` 当真人参考；禁止保存头像 URL。
- 禁止中文或中英混排正式海报；禁止 UI 截图、SVG/Canvas 栅格化海报。
- 禁止用整页 transform 缩放普通 DOM UI。

## 11. 垂直切片验收

- 单一 Rooftop Apartment 入口，无 Cartridge 选择器；一次行动、检定、公共状态变化、关系事件、内联图片、World 抽屉和阶段摘要可玩。
- 390×844 与 320×568 下最新回复、玩家头像、图片、快速回复、输入框和三项数值同时可达，无横向溢出。
- `?avatar_url=<public HTTPS>` 下行动、住户页和生图请求使用同一头像；无头像时 UI 使用默认 `U`，生图退回 txt2img。
- Aigram AI、stateful API 或生图失败时显示原位可恢复状态；剧情接口提供“重试这一步”，不把模板演示或重复文本伪装成正式推进。确定性演示只通过调试参数进入。
